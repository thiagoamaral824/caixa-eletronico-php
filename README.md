# 💳 Caixa Eletrônico em PHP

Um simulador simples de caixa eletrônico desenvolvido em PHP para praticar conceitos fundamentais de programação e lógica.

## 📖 Sobre o projeto

Este projeto foi criado durante meus estudos de PHP com o objetivo de aplicar conceitos básicos da linguagem em uma aplicação de terminal.

O sistema simula operações comuns de um caixa eletrônico, permitindo consultar saldo, realizar saques, efetuar depósitos e encerrar a aplicação, tudo por meio da interação com o usuário via terminal.

## ✨ Funcionalidades

- Consultar saldo atual
- Realizar saques
- Realizar depósitos
- Validar saldo insuficiente
- Validar valores de entrada
- Exibir mensagens para operações inválidas
- Encerrar a aplicação de forma controlada

## 🛠️ Conceitos praticados

- Variáveis
- Operadores aritméticos
- Operadores lógicos
- Estruturas condicionais (`if`, `elseif`, `else`)
- Estruturas de repetição (`while`)
- Entrada de dados com `fgets(STDIN)`
- Conversão de tipos (`int` e `float`)
- Controle de fluxo

## 🚀 Como executar

### Pré-requisitos

- PHP instalado na máquina

### Executando o projeto

Clone o repositório:

```bash
git clone https://github.com/SEU-USUARIO/SEU-REPOSITORIO.git
```

Acesse a pasta do projeto:

```bash
cd SEU-REPOSITORIO
```

Execute o arquivo:

```bash
php caixa-eletronico.php
```
